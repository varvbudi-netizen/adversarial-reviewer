# adversarial-reviewer — критическая проверка и неудобные вопросы

Один навык для двух задач: найти сбои в реализации и заметить, чего не хватает пользователю для завершения действия. Он объединяет авторские `adversarial-reviewer` и `awkward-questions` от [varvbudi-netizen](https://github.com/varvbudi-netizen), а также сохраняет специализированные справочники, ранее адаптированные из набора Anthropic.

Например, проверка кода выясняет, почему ошибка сохранения превращается в сообщение об успехе. Неудобный вопрос помогает увидеть другой пробел: как человеку понять, сохранилась ли работа, если интерфейс вообще этого не показывает?

## Как устроена проверка

- Агент устанавливает область по поручению и доступным материалам, читает реализацию и связанные части.
- Для подозрения строит конкретный сценарий: условия → действие → неверный результат и последствия.
- В пользовательском сценарии проверяет отмену, выход, состояние данных, обрыв операции и другие недостающие возможности.
- Проверяет альтернативные пути, прежде чем утверждать, что функции нет.
- Объединяет повторяющиеся находки; отделяет подтверждённые проблемы от гипотез.
- Указывает тяжесть последствий, доказательства и границы проверки. Для продуктового пробела добавляет вопрос и предварительный масштаб исправления.

Обязательного числа находок нет. Навык требует честно сообщать, если существенных проблем не найдено. Запрос проверки сам по себе не разрешает менять проверяемый проект. Независимый агент необязателен; отдельные исходные навыки для работы не нужны.

## Установка

Через каталог навыков, если установлен Node.js:

```sh
npx skills add varvbudi-netizen/adversarial-reviewer --skill adversarial-reviewer
```

Либо скопируй репозиторий целиком в свободную папку навыка. Команды для Windows и PowerShell:

Кодекс:

```powershell
git clone https://github.com/varvbudi-netizen/adversarial-reviewer.git "$env:USERPROFILE\.codex\skills\adversarial-reviewer"
```

Claude Code:

```powershell
git clone https://github.com/varvbudi-netizen/adversarial-reviewer.git "$env:USERPROFILE\.claude\skills\adversarial-reviewer"
```

Если навык с таким именем уже установлен, сначала сохрани его отдельно; клонирование требует свободной папки. В других системах обычные пути — `~/.codex/skills/adversarial-reviewer` и `~/.claude/skills/adversarial-reviewer`. Сохрани папку `references/` и документы об источниках и лицензиях. После установки обнови список навыков или начни новый сеанс.

## Примеры запросов

```text
Используй adversarial-reviewer. Проверь изменения этой ветки относительно main.
Ищи воспроизводимые сбои и нарушения существующего поведения.
Ничего не исправляй; покажи доказательства и границы проверки.
```

```text
Используй adversarial-reviewer для раздела редактирования товаров.
Проверь код и задай неудобные вопросы: как отменить правку,
понять, что она сохранилась, и восстановиться после обрыва связи?
Не считай вопрос доказанным дефектом без проверки.
```
