# Происхождение проверок

Адаптировано из `pr-review-toolkit@claude-plugins-official`, локальной поставки Anthropic, сохранённой 7 сентября 2026 года. [Лицензия исходных материалов](pr-review-toolkit-LICENSE.txt).

Источник: https://github.com/anthropics/claude-plugins-official/tree/main/plugins/pr-review-toolkit

| Исходный материал | Сохранённая методика |
|---|---|
| code-reviewer | Область проверки, требования проекта, последствия и доказанность |
| code-simplifier | Оценка сложности с сохранением поведения, без автоматической правки |
| silent-failure-hunter | Путь ошибки, запасное поведение, повторные попытки и диагностика |
| pr-test-analyzer | Значимые регрессии, отрицательные сценарии и качество проверок |
| type-design-analyzer | Инкапсуляция, допустимые состояния и обеспечение свойств данных |
| comment-analyzer | Соответствие комментариев реальному контракту и реализации |

Удалены привязка к агентам Claude, безусловный запуск всех процедур, смешение уверенности с тяжестью ошибки и правила журналирования чужого проекта. Исправление кода не включается автоматически в запрос проверки.
